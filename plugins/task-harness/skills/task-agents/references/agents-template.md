# 저장소 지침 템플릿

필요한 항목만 작성하고 근거가 없는 명령이나 경로는 만들지 않습니다. 기존 지침에서는 필요한 부분만 갱신합니다.

```markdown
# 저장소 작업 지침

## 목적과 진입점

목적:

| 경로 | 역할 | 확인 근거 |
| --- | --- | --- |
| | | |

## 실행과 검증

| 작업 위치 | 명령 | 근거 파일 | 설정 확인 / 실행 성공 / 실행 실패 / 미확인 | 시점과 확인 범위 |
| --- | --- | --- | --- | --- |
| | | | | |

## 문서 탐색

| 정보 | 원본 경로 | 존재 확인 / 예정 |
| --- | --- | --- |
| | | |

## 작업 원칙

- 현재 흐름의 수용 조건이 확정되면 구현 시작
- 파일별 편집 책임 구분과 기존 변경 보존
- 실제 검증 근거에 따른 완료 판단

## 적용 제약

| 제약 | 근거 | 적용 범위 |
| --- | --- | --- |
| | | |
```

적용 제약은 현재 요청이나 실제 환경에서 확인한 것만 기록합니다. 위 작업 원칙도 기존 사용자 규칙을 대체하지 않도록 조정합니다.
