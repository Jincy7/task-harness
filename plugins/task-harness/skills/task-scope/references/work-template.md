## 결정

요구와 범위에 영향을 주는 결정만 근거와 함께 기록합니다. 실제 구현 결과와 검증 이력은 작업 보고에 둡니다.

## 작업 체크리스트

- [ ] T1 현재 흐름의 첫 작업 (수용 조건 ID)
- [ ] T2 현재 흐름의 검증 작업 (수용 조건 ID)

항목 완료 시 실제 작업 보고 링크를 붙입니다. 작업 계약이나 결과 표를 체크리스트에 추가하지 않습니다. 구현 완료에는 수용 조건의 실행 근거가 필요합니다. 범위 결정 완료는 제품 완료를 뜻하지 않습니다.
